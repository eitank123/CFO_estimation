# jobs/archive

Cluster job scripts (`*.sh`), their queue files (`queue_*.txt`) and command lists (`smoke*_cmds.txt`)
that were **last modified before 2026-11-13**, moved out of `jobs/` on 2026-11-15. Jobs from
2026-11-13 on stay in `jobs/`. The scripts still `cd` to the cluster folder and reference
`jobs/<name>`, so to re-run one, copy it back into `jobs/` first.

Grouped by entry point (the Python script the job runs):

| Folder | Entry point |
|---|---|
| `lowrate/` | `polar_ber_experiment.py` (pilot / low-rate BLER runs, `add*` jobs), `train_*.py`, `cfo_*.py` NN training without `BLIND_STUDY=small_cfo` |
| `blind_a16/` | `blind_ber.py` without `BLIND_STUDY=small_cfo`, other `blind_*.py` (`blind_fast`, `blind_cfo`, `blind_nn`, ...), `blind/smoke/*` (incl. `smoke-N.sh` + `smoke*_cmds.txt`) |
| `small_cfo_a17/` | `blind_ber.py` with `BLIND_STUDY=small_cfo`, `small_*.py` (`small_race`, `small_ck_nn`, ...), and `polar_ber_experiment.py` / `train_*.py` runs with `BLIND_STUDY=small_cfo` |
| `est3/` | `est3/*` (`run_bler.py`, `run_est.py`, `nn.py`), incl. `run_est3-*.sh` |
| `cluster_run/` | other `run_*.sh` (generated by `cluster.py run`) |
| `testing_r1/` | first-round `BLIND_IMPLEMENTATION/testing/run.py` (`testing/run.py`) jobs before 2026-11-13 |
| `cancelled/` | jobs cancelled before finishing: `e4-10la`, `e4-10lb`, `b10la`, `b10lb` (logs in `logs/archive/cancelled/`) |

A `queue_*.txt` sits next to the scripts of the group most of its `@jobs/<name>.sh` entries belong to.
